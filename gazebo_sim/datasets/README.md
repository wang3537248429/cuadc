# 本地训练数据

当前公开源码不包含数据集、样例或 Release 数据附件。已有数据使用了再分发许可尚未确认的竞赛图案，仿真渲染和增强处理不会自动赋予分发权。

本目录可用于本地保存 YOLO 数据，通常按 `<数据集>/task1/`、`<数据集>/task2/` 分开，每个任务下保存 `images/`、`labels/`、`data.yaml` 和来源清单。数据准备与评估工具见 `../tools/vision_training/README.md`。

自行准备数据时保留素材来源、许可、划分、随机种子和校验值。训练、验证与测试应按原始样本隔离，不能把同一原图的不同增强副本分到不同划分。

没有本地数据时，数据完整性专用测试显示跳过。其他源码测试仍可执行；跳过不代表识别效果通过。
