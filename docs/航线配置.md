# 航线配置

## 公开 A/B 示例

公开配置使用 ArduPilot 的 SITL 原点：纬度 `-35.363261`、经度 `149.165230`、海拔 `46 m`。这些数值用于仿真。

| 区域 | 任务文件 | 场地文件 |
| --- | --- | --- |
| A | `gazebo_sim/config/missions/official_route_a.waypoints` | `gazebo_sim/config/arena_official_a.json` |
| B | `gazebo_sim/config/missions/official_route_b.waypoints` | `gazebo_sim/config/arena_official_b.json` |

公开任务由原始任务平移并按纬度修正经度尺度，保留局部东北方向的航点几何、序号、命令和相对高度。绝对高度同步迁移到公开原点。原始实物航线另行私下保存，不随项目公开。

A/B 目标区按共用起降区中心进行 180° 点对称。HOME、起始方向、场地尺寸和航线范围由所选场地文件共同确定；不要把 A 航线与 B 场地混用。边界依据各区域配置计算，不能用早期默认 300 m 判断全部示例。

## 地面站上传

```bash
./gazebo_sim/scripts/run_sim.sh --official-route A
```

在 Mission Planner 的 PLAN 页载入对应文件，检查 HOME 与首个有效飞行点，上传后读回核对。飞控执行地面站上传的任务；启动参数只选场地，不代替上传操作。

默认任务链路使用任务中预留的动态条目。只检查上传任务的原样执行时，可显式使用 `--preserve-uploaded-route`；该模式不作为动态投水验收。

## 使用其他航线

保留公共示例不动，把设备与真实航线放在项目外的私有目录。制作公开副本时可运行：

```bash
python3 scripts/anonymize_mission.py --help
```

工具接收原始 WPL 110 文件、一个新的输出路径和原始坐标原点，拒绝覆盖现有输出。坐标原点参数属于本地资料，使用后不要把终端记录或脚本调用原样加入文档。

迁移后需同步检查场地原点、局部坐标、绝对高度和飞控 HOME；工具不会替使用者调整任意场地或验证其飞行安全。检查航线命令与高度，再分别完成 A/B 仿真。

## 发布检查

```bash
python3 scripts/privacy_audit.py
python3 scripts/build_release_packages.py public --directory dist/cuadc-public
```

审计会检查 WPL 坐标以及 JSON 中的经纬度字段，拒绝公开示例范围外的值。不要为真实航线增加散列白名单。公开包中不保留原始比赛场地名、备份、飞行日志或真实位置报告。
