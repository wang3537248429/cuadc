# 项目结构

仓库按部署环境分为仿真、机载和地面站三个模块。运行脚本放在所属模块内，仓库级检查与导出工具集中在根目录 `scripts/`。命令默认从仓库根目录执行。

## 目录布局

```text
cuadc/
├── README.md                 项目入口与文档索引
├── docs/                     统一操作、配置和发布文档
├── scripts/                  跨模块验证、审计、导出及其测试
├── gazebo_sim/
│   ├── src/cuadc_sim/        仿真 Python 代码
│   ├── config/               场地、相机、航线及飞控参数
│   ├── plugins/              Gazebo C++ 插件和 CMake 配置
│   ├── patches/              固定版本的上游插件补丁
│   ├── worlds/               SDF 世界模板
│   ├── models/               飞机、场景模型及本地视觉权重目录
│   ├── assets/               上游素材、类别表及本地靶标目录
│   ├── datasets/             数据说明；训练数据仅本地保存
│   ├── scripts/              安装、启动、录制与仿真验收工具
│   ├── tools/vision_training/ 数据准备、训练和离线评估
│   └── tests/                仿真模块测试
├── onboard/
│   ├── src/cuadc_onboard/    机载视觉、任务与 MAVLink 路由
│   ├── config/               机载配置、航线及飞控参数示例
│   ├── scripts/              安装、部署、维护与离线诊断
│   ├── systemd/              服务模板
│   ├── udev/                 相机与飞控设备规则
│   ├── assets/targets/       类别映射
│   ├── models/vision/        本地权重与校验清单
│   └── tests/                机载模块测试
├── ground_station/
│   ├── cuadc_ground_station/ 中文监控与 TLOG 读取

│   ├── run.sh                Linux 启动入口
│   └── build_windows.*       Windows 打包入口
├── .github/                  CI、问题与合并请求模板
├── LICENSES/                 第三方许可全文
└── dist/                     本地产物，不提交 Git
```

## 代码入口

| 功能 | 文件 |
| --- | --- |
| 仿真进程启动与回收 | `gazebo_sim/src/cuadc_sim/supervisor.py` |
| 场景与场地几何 | `scenario.py`、`field_layout.py`、`arena.py` |
| 地面站任务与遥测通信 | `mission.py`、`mavlink_io.py` |
| 仿真任务执行 | `companion.py`、`route_state.py` |
| 相机与时序 | `camera_stream.py`、`camera_packet.py`、`frame_timing.py` |
| 在线视觉 | `vision_service.py`、`vision.py`、`pixel_rois.py` |
| 投水计算与结果 | `ballistics.py`、`results.py` |
| 机载命令入口 | `onboard/src/cuadc_onboard/cli.py` |
| 机载运行与路由 | `runtime.py`、`router.py`、`mavlink_io.py` |
| 中文监控入口 | `ground_station/cuadc_ground_station/app.py` |

表中未带路径的仿真文件均位于 `gazebo_sim/src/cuadc_sim/`；机载文件位于 `onboard/src/cuadc_onboard/`。视觉程序从相机像素获得检测结果；场景真值用于渲染和离线评分。修改这部分代码时，必须保留二者之间的输入边界。

两个部署模块分别保留弹道、相机和视觉代码，机载程序不依赖仿真包。修改同名算法时应核对两端行为并运行对应测试。

## 配置与本地资源

版本控制保存可复现的公共示例，设备、网络和真实航线使用本地配置。`*.local.yaml`、`*.local.json`、日志、TLOG、录像和训练数据不提交；两套已审核运行权重以压缩归档提交。公开文件范围由 `scripts/release_policy.py` 定义，Git 忽略规则与导出审计共同检查。

| 路径 | 内容 | 是否发布 |
| --- | --- | --- |
| `gazebo_sim/config/` | 脱敏场地、航线、相机与飞控参数 | 是 |
| `assets/targets/catalog.json` | 类别和值映射 | 是 |
| `assets/targets/reference/` | 本地靶标图片 | 否 |
| `models/vision/*.pt.gz` | 两套公开运行权重归档 | 是（仅列入清单的运行权重） |
| `models/vision/*.pt` | 安装后解压的运行文件 | 否 |
| `datasets/` 中的训练文件 | 数据、标签与训练划分 | 否 |
| `gazebo_sim/.venv/`、`.deps/` | 已安装环境与构建依赖 | 否 |
| `gazebo_sim/.runtime/` | 状态、临时世界、SITL 工作目录及日志 | 否 |
| `gazebo_sim/runs/` | 每次仿真结果与 `latest.json` | 否 |
| `dist/` | 审计结果、测试报告和公开导出 | 否 |

## 工具维护

常用命令索引见 [`scripts/README.md`](../scripts/README.md)。训练目录仅保留当前数据与模型流程，详见[训练工具说明](../gazebo_sim/tools/vision_training/README.md)。旧版云端训练、单类数字检测、重复推理脚本和历史验收报告已退出公开源码。

新增文件按所属模块归档。测试与模块同目录；示例放 `config/`；临时调试结果放 `.runtime/`；评估输出放 `runs/`。不要在根目录新增独立应用代码、截图或训练产物。

清理可重建产物使用 `./scripts/clean_generated.sh`。该命令删除运行记录和 `dist/`，执行前应保存需要的结果并退出仿真。它保留本地靶标、数据和视觉权重；加 `--dependencies` 会同时删除环境和下载依赖，下次需重新安装。
