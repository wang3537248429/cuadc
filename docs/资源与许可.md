# 资源与许可

## 当前发布范围

公开源码包含原创代码、配置示例、测试、类别表、校验清单和已注明许可的上游仿真资产。以下内容仅在本地保留，不进入 Git、源码包或本次 Release 附件：

- 竞赛靶标图案及其裁剪、重绘或渲染副本。
- 由这些图案生成的训练集、验证集、测试集和样例。
- 训练数据、训练记录和训练用预训练权重。
- 规则 PDF、真实航线、原始日志、TLOG 和录像。

当前没有确认上述靶标素材的再分发授权，因此靶标图片不进入源码或 Release 附件。运行用 `task1_v4m_best.pt.gz` 和 `task2_sim_digits_v1.pt.gz` 已获项目发布者授权并随源码提供；如果替换模型或训练数据，必须重新完成许可和元数据审查。

## 配置完整仿真的本地资源

靶标图片仍需先取得合法使用权。仓库中的运行权重归档可直接由安装脚本校验；清单仍只说明文件身份，不替代对替换资源的许可审查。

| 资源 | 仿真路径 |
| --- | --- |
| 类别和值映射 | `gazebo_sim/assets/targets/catalog.json` |
| 图形、数字靶标图片 | `gazebo_sim/assets/targets/reference/` |
| Task 1 权重 | `gazebo_sim/models/vision/task1_v4m_best.pt.gz`（安装时解压） |
| Task 2 权重 | `gazebo_sim/models/vision/task2_sim_digits_v1.pt.gz`（安装时解压） |
| 图片校验清单 | `gazebo_sim/assets/targets/REFERENCE_SHA256SUMS` |
| 模型校验清单 | `gazebo_sim/models/vision/MODEL_SHA256SUMS` |

图片的完整相对路径可在 `REFERENCE_SHA256SUMS` 中查看。自行替换素材时需满足场景引用的文件名、颜色和类别映射，并重新训练或选择匹配模型；Task 2 使用十位、个位的类别表示，旧版整板单类或 100 类模型不能直接替代。

替换时保留原始清单副本，对确认来源的文件重新生成校验清单。仅在对应目录明确列出需要的文件，避免将训练临时文件纳入运行清单。模型类别、输入尺寸、任务值映射和 `onboard/config/onboard.yaml` 中的模型设置必须一致。

在仓库根目录检查：

```bash
python3 scripts/check_local_resources.py --project gazebo_sim --require
python3 scripts/check_local_resources.py --project onboard --require
```

机载安装器会从 `onboard/models/vision/` 的公开归档生成 `.pt` 文件，校验清单也在该目录。校验失败时应查明是文件损坏、模型版本变化还是资源缺失，不应直接忽略错误。

## 资源记录

对准备使用或分发的每组资源，记录作者、来源链接、取得日期、许可证、训练数据来源、修改内容与 SHA-256。若由授权人单独许可，保存许可证明并确认它覆盖预期用途。

PyTorch 检查点可能携带训练路径、账号和数据集信息。导入可信检查点前检查元数据；公开前同时检查图片 EXIF/XMP、压缩包文件名和资源路径。不要对不可信权重直接调用 `torch.load`。

训练工具位于 `gazebo_sim/tools/vision_training/`。工具代码的许可证不自动覆盖输入图片、派生数据或输出权重。现有 `publish_models.py` 用于本地模型整理，运行它不等于获得发布授权。

## 验证范围

没有靶标图片的干净源码可以运行配置、通信、几何、弹道、导出和隐私相关测试；公开权重可直接用于安装后的模型加载。依赖本地靶标数据的专用测试明确跳过。

完整视觉与飞行验收需另行运行，并保留在线检测、任务结果、实际落点、返航及停稳记录。更换资源或航线后重新验收，不能引用旧模型或旧场地的结果作为当前版本的通过依据。
